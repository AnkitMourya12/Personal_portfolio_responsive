## Prerequisites

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/ankitmourya8233/react-portfolio.git
    ```
2. Navigate to the project directory:
    ```bash
    cd react-portfolio
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage
1. Start the development server:
    ```bash
    npm start
    ```
2. Open your browser and go to `http://localhost:3000`

## Deployment on Netlify
Follow these steps to deploy your portfolio on **Netlify**:

1. Create an account on [Netlify](https://www.netlify.com/).
2. Install the Netlify CLI (optional for manual deployment):
    ```bash
    npm install -g netlify-cli
    ```
3. Build the project:
    ```bash
    npm run build
    ```
4. Drag and drop the `build` folder to the Netlify dashboard for quick deployment.

Alternatively, deploy using the CLI:
```bash
netlify deploy --prod
```
5. Netlify will provide a live URL for your portfolio.
